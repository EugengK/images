# PixView

맥용 가벼운 이미지 뷰어 (Swift / SwiftUI, macOS 14+). 폴더를 열면 썸네일을 필요한 만큼만 점진적으로 읽어서 로딩이 오래 걸리지 않도록 만드는 것이 목표입니다.

## 빌드 (맥에서)
```bash
xcode-select --install   # Command Line Tools가 없을 때만
./build_app.sh           # build/PixView.app 생성
open build/PixView.app
```
Xcode로 열려면 `open Package.swift`.

## 편집 기능
자르기·업스케일·형식 변환은 **원본을 건드리지 않고 같은 폴더에 사본**을 저장합니다.
- 업스케일은 Lanczos 보간 + 약한 샤프닝입니다. AI 초해상도가 아닙니다.
- 형식 변환: JPEG / PNG / HEIC.

## 알려진 한계 (v0.1)
- 즐겨찾기는 앱 내부(UserDefaults)에 파일 경로로 저장됩니다. 앱 밖(Finder)에서 옮기거나 이름을 바꾸면 연결이 끊깁니다.
- 폴더 안의 하위 폴더는 재귀적으로 읽지 않습니다 (툴바 메뉴로 이동).
- 썸네일 디스크 캐시는 아직 없습니다.
